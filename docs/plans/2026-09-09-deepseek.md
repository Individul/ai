# Plan: DeepSeek V4 Flash ca al treilea motor

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Chatul poate rula și pe DeepSeek V4 Flash (plată per token, cache automat pe prefix), ales din Admin ca orice alt model.

**Architecture:** DeepSeek e OpenAI-compatibil, deci refolosim clientul din `src/lib/zai.ts` (cerere, răspuns, erori) cu altă adresă și altă cheie; `motor.ts` alege cheia și baza după `TARIFE[model].motor`, iar tot ce e „motor cu text extras” (Z.AI sau DeepSeek) trece prin același drum: texte din R2 → `context.ts` → client → citări. Costul din jurnal folosește tokenii din cache la prețul de cache, ceea ce corectează și GLM.

**Tech Stack:** Astro 7 pe Cloudflare Workers, D1, R2, vitest în workerd. Fără SDK.

**Decizii (Dumitru, 9 sept. 2026):** doar `deepseek-v4-flash` în select (Pro se adaugă dintr-o linie). Tarif public (sept. 2026): 0,14 $/M intrare, 0,0028 $/M intrare din cache, 0,28 $/M ieșire; context 1 M. Cache-ul e automat, pe prefix: promptul de sistem + documentele stau înaintea istoricului, deci în modul „integral” a doua întrebare pe aceeași culegere plătește documentele la preț de cache. Bugetul de context și textul extras din PDF-uri sunt cele existente.

### Task 1: Tarife și motorul `deepseek` — `src/lib/validare.ts`

- `Motor` devine `"gemini" | "zai" | "deepseek"`; `Tarif` primește `intrare_cache?: number` ($/M pentru tokenii din cache).
- `TARIFE["deepseek-v4-flash"] = { motor: "deepseek", intrare: 0.14, intrare_cache: 0.0028, iesire: 0.28, eticheta: "DeepSeek V4 Flash · plată per token, cache automat" }`; GLM-5.3-Flash primește `intrare_cache: 0.03`, GLM-5.3 `0.26`.
- `NUME_MOTOR: Record<Motor, string> = { gemini: "Gemini", zai: "Z.AI", deepseek: "DeepSeek" }`, pentru etichete în pagini.
- Test (`validare.test.ts`): `motorModel("deepseek-v4-flash") === "deepseek"`; tariful are `intrare_cache`; `NUME_MOTOR.deepseek === "DeepSeek"`. RED → GREEN.

### Task 2: Costul cu cache — `src/lib/gemini.ts` `costMicrodolari(model, intrare, iesire, cache = 0)`

- `(intrare − cache) × intrare + cache × (intrare_cache ?? intrare) + iesire × iesire`, rotunjit.
- Test (`zai.test.ts`): `costMicrodolari("deepseek-v4-flash", 676_000, 600, 676_000) === 2061`; fără cache `94_808`; GLM cu cache `100_000, 500, 90_000` → `10_000×0.15 + 90_000×0.03 + 500×0.5 = 4_450`; Gemini ignoră cache-ul. RED → GREEN.

### Task 3: Clientul OpenAI-compatibil acoperă și DeepSeek — `src/lib/zai.ts`

- `BAZA_DEEPSEEK = "https://api.deepseek.com"`.
- `extrageRaspunsZai`: `tokens_cache = usage.prompt_cache_hit_tokens ?? usage.prompt_tokens_details?.cached_tokens ?? 0`.
- `EroareZai.contextPreaLung` recunoaște și mesajele OpenAI-style: `/exceeds max length|maximum context length|context length|too long/i`.
- Test: răspuns cu `usage: { prompt_tokens: 1000, prompt_cache_hit_tokens: 900, prompt_cache_miss_tokens: 100, completion_tokens: 20 }` → `tokens_cache 900`; `new EroareZai(400, "This model's maximum context length is 1048576 tokens").contextPreaLung === true`. RED → GREEN.
- Parametrul `thinking: {type: "disabled"}` rămâne în cerere pentru ambele; se verifică pe viu la Task 6 dacă DeepSeek îl acceptă (altfel se scoate pentru `deepseek`).

### Task 4: Orchestrarea — `src/lib/motor.ts`

- `Mediu` primește `DEEPSEEK_API_KEY?`. `cheieMotor(env, motor)` → cheia potrivită sau `undefined`; `bazaMotor(env, motor)` → `ZAI_API_BASE || BAZA_ZAI` sau `BAZA_DEEPSEEK`.
- `disponibilePentruChat`: orice motor ≠ gemini numără sursele cu text.
- `raspunde`: motor gemini → ca acum; altfel `raspundeText` (fostul `raspundeZai`) cu cheia/baza motorului; `cost_microdolari` cu `tokens_cache`; `credite` doar la zai (0 altfel, prin `crediteZai`).
- Test (`motor.test.ts`): `disponibilePentruChat("deepseek", null, SURSE) === 2`; `raspunde` pe `deepseek-v4-flash` cu `DEEPSEEK_API_KEY: "test"` trimite cheia „test” și baza DeepSeek la apelul injectat, `credite 0`, `cost_microdolari` cu cache; fără `DEEPSEEK_API_KEY` → 503. RED → GREEN.

### Task 5: Rute, pagini, mediu, documentație

- `src/pages/api/chat/index.ts`: cheia prin `cheieMotor`.
- `src/scripts/chat.ts`: așteptarea lungă pentru orice `data-motor !== "gemini"`.
- `src/pages/admin/cataloage/[id].astro`, `src/pages/admin/consum.astro`: etichete prin `NUME_MOTOR`; lămurirea din consum acoperă DeepSeek (cache automat, fără cotă); `descriereModel` arată și prețul de cache.
- `src/env.d.ts`, `.dev.vars.example`, `wrangler.jsonc` (comentariu secret), `README.md`, `CLAUDE.md` (convenția: `zai.ts` e clientul OpenAI-compatibil pentru Z.AI și DeepSeek).
- `npm test`, `npm run check`, build.

### Task 6: Verificare pe viu și deploy

- Dumitru pune `DEEPSEEK_API_KEY` în `.dev.vars` (cont pe platform.deepseek.com, sold preplătit).
- `curl` din Node: cerere mică cu `thinking: {type:"disabled"}` (acceptat?), câmpurile `usage`, apoi două cereri identice cu context mare ca să vedem `prompt_cache_hit_tokens` la a doua; mesajul la context prea lung.
- `npm run dev:worker`: model `deepseek-v4-flash` în Admin, o întrebare pe culegerea de test; jurnalul arată cache și cost.
- Secretul în producție prin stdin (Dumitru), `npm run deploy`, comutare din Admin.

## Stare (11 septembrie 2026): V4.1 Flash

DeepSeek a lansat V4.1 Flash pe 10 sept. 2026 (arhitectură nouă, 552 B parametri cu 8–16 B activi, context 1 M, MIT) și a retras V4 Flash și V4 Pro (redirecționate spre 4.1 din 14 sept.). În API modelul se numește `deepseek-flash`; `deepseek-v4-flash` mai e acceptat, dar răspunde tot 4.1 (câmpul `model` din răspuns). Făcut:
- `TARIFE["deepseek-flash"]` (0,15 / 0,003 cache / 0,60 $ per M, ore libere) cu `varf` (factor 2, 01–04 și 06–10 UTC, luni–vineri); `factorTarif` în `validare.ts`, aplicat în `costMicrodolari`. `deepseek-v4-flash` marcat `retras` (nu mai apare în Admin).
- Producția comutată pe `deepseek-flash`.
- Verificat pe viu: cerere directă la API (răspuns corect, `usage` cu `prompt_cache_hit_tokens`), apoi cap-coadă prin `/api/chat` local: citări corecte pe pagină, jurnal cu `deepseek-flash`, cost 97 µ$ la 345/76 tokeni în afara orelor de vârf.
- Față de V4: ieșirea costă dublu (0,60 față de 0,28), intrarea și cache-ul la fel; la 600–800 tokeni per răspuns diferența e sub o zecime de cent. Riscul de date (China, condiții care permit antrenarea pe datele din API) rămâne cel asumat la V4.
